## 3. 问题分析

### 3.1 训练不收敛

训练曲线显示明显的不稳定性：
- 平均奖励在0.315至1.275之间剧烈波动
- 没有呈现预期的上升趋势
- 最佳性能出现在中期(Epoch 6)，之后性能反而下降

### 3.2 策略损失异常

策略损失(Policy Loss)接近于零(约1e-10量级)，这是一个严重的异常信号：
- 表明策略网络几乎没有在更新
- 可能原因：梯度消失、奖励信号过弱、或网络结构问题

### 3.3 验证指标不理想

- 覆盖率最高仅60.5%，最终下降至45.7%
- HU合规率波动极大(1.1%~55.1%)，表明模型预测不稳定
- 两个指标之间缺乏一致的相关性

### 3.4 探索不足

熵值(Entropy)始终维持在0.56-0.63的狭窄区间，表明：
- 策略探索程度有限
- 模型可能陷入局部最优

## 5. 后续方案

鉴于当前强化学习方法效果不佳，建议通过以下替代方式进行分析和改进：

### 5.1 参数调整方案
- 增大Batch Size (8 → 32或64) 以稳定训练
- 适当增大Entropy系数 (0.01 → 0.05) 增强探索
- 检查并调整奖励函数的scale
- 增加训练轮数至50-100 epochs

### 5.2 替代方法
- **监督学习微调**: 使用高质量标注数据进行传统监督学习
- **半监督学习**: 结合少量标注数据和大量未标注数据
- **后处理优化**: 使用CRF或形态学方法优化分割边界
- **集成学习**: 结合多个模型的预测结果

### 5.3 诊断建议
- 可视化奖励函数各分量的分布
- 检查梯度流是否正常
- 分析Teacher模型的预测质量
