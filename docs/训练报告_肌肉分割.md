## 1. 项目概述

本项目旨在使用深度学习方法对CT扫描图像中的肌肉组织进行自动分割。采用2D U-Net网络架构，对10种肌肉结构进行多通道语义分割。

## 3. 模型架构

### 3.1 网络结构
采用经典的 **2D U-Net** 架构：

```
编码器 (Encoder):
  - 输入层: 1通道 (灰度CT图像)
  - 特征层: [32, 64, 128, 256]
  - 每层: Conv3x3 -> BN -> ReLU -> Conv3x3 -> BN -> ReLU -> MaxPool2x2

瓶颈层 (Bottleneck):
  - 特征维度: 512

解码器 (Decoder):
  - 上采样: ConvTranspose2d (2x2)
  - Skip Connection: 与编码器对应层特征拼接
  - 特征层: [256, 128, 64, 32]

输出层:
  - Conv1x1 -> 10通道 (10种肌肉)
```

### 3.2 模型参数
- **总参数量**: 约 7.8M
- **输入通道**: 1 (灰度图像)
- **输出通道**: 10 (10种肌肉)

## 5. 训练结果

### 5.1 训练过程摘要

训练因**达到准确率阈值**而提前停止，实际训练了 **5个epoch**。

### 5.2 各轮次指标详情

- 验证Dice达到 **94.45%**，超过预设阈值 **93%**

## 8. 结论与建议

### 8.1 训练结论

1. **模型性能优秀**: 验证Dice达到 94.45%，IoU达到 91.85%，对于10类肌肉分割任务来说是很好的结果。

2. **训练效率高**: 仅用5个epoch（约9小时）就达到了预设的准确率阈值，早停机制有效避免了过度训练。

3. **无过拟合问题**: 训练集和验证集的性能差距很小（约1.15%），模型泛化能力良好。

4. **学习率策略有效**: 余弦退火学习率调度帮助模型平稳收敛。

### 8.2 后续建议

1. **模型应用**: 当前模型可以直接用于CT图像的肌肉分割任务。

2. **进一步优化**: 如需更高精度，可以考虑：
   - 增加训练数据
   - 使用数据增强
   - 尝试更深的网络架构（如 U-Net++, Attention U-Net）
   - 针对表现较差的肌肉类别进行针对性优化

3. **部署准备**: `best_model.pth` 包含最佳模型权重，可用于推理部署。
