# Muscle Segmentation Project Codebase Structure Overview

This document provides a detailed explanation of the folder structure and contents of this codebase. This project focuses on leveraging transfer learning and semi-supervised techniques to extend muscle segmentation from limited spinal muscle labels to a comprehensive segmentation of the entire muscle groups, with a particular emphasis on abdominal muscles.

## 📁 Directory Structure Overview

### 1. Core Scripts (`scripts/`)
This directory contains the core working scripts of the project, including all training, inference, and analysis scripts.

*   **Training Scripts (by evolution)**:
    *   `train_muscle_rl.py`: Early exploration using Reinforcement Learning (PPO) for muscle region discovery.
    *   `train_muscle_transfer_v2.py`: **V2 version**, trained directly with TotalSegmentator labels, incorporating hard HU constraints, but yielding conservative results.
    *   `train_muscle_transfer_v3.py`: **V3 version**, implementing an "Expand then Refine" strategy (`ExpandThenRefineLoss`), encouraging coverage of all muscle-like regions, but leading to organ misclassification.
    *   `train_muscle_transfer_v5_l3.py`: **V5 version (current best)**, introducing L3 vertebral focus, explicit organ exclusion, and attention mechanisms to resolve the organ misclassification issue.
    *   `train_fat_segmentation.py`: Standalone training script for fat segmentation.
    *   `train_abdominal_wall_muscle.py`: Specific training script for abdominal wall muscles.

*   **Analysis and Utilities**:
    *   `muscle_analysis_enhanced.py`: Enhanced muscle analysis script.
    *   `muscle_fat_web_app.py`: Web-based (Streamlit/Web) tool for muscle-fat analysis visualization.
    *   `generate_report_figures.py`: Helper script for generating figures used in reports.

### 2. Documentation and Reports (`docs/`)
This directory stores project documentation, experimental reports, and progress records.

*   **`muscle_transfer_evolution/`**: **[Recommended Reading]** Contains the comprehensive project evolution summary report (`project_evolution_report_v5_cn.md`), which deeply analyzes the technical decision-making process from RL to V5.
*   `muscle_transfer_v3/`, `muscle_transfer_v5/`: Detailed experimental reports and visualization results for specific versions.
*   `MODEL_GUIDE_*.md`: Model usage guides (Chinese/French versions).
*   `training_report_*.md`: Detailed records of the training process.
*   `figures/`: Assets like architectural diagrams and trend charts used in reports.

### 3. Output Directories (`outputs*/`)
These directories store model weights, logs, and visualization results from training. Different folders correspond to different experimental versions.

*   **`outputs_v5/`**: Outputs from the V5 experiment (L3 focus + organ exclusion), including the best model `best_model.pth`.
*   **`outputs_muscle_transfer_v3/`**: Outputs from the V3 experiment (Expand then Refine).
*   **`outputs_muscle_transfer_v2/`**: Outputs from the V2 experiment (Strong Supervision).
*   **`outputs_rl_muscle/`**: Outputs from the Reinforcement Learning experiment.
*   **`outputs_fat/`**: Outputs from the fat segmentation model.
*   `outputs/`, `outputs_backup/`: Default or older output backups.

### 4. Analysis Results (`analysis_output/`)
This directory contains statistical data and charts generated by analysis scripts.
*   `analysis_stats.json`: Analysis statistics.
*   `*.png`: Various slice analysis visualization plots (e.g., `slice_0035_analysis.png`).

### 5. Application (`muscle_viewer_app/`)
A standalone application module for interactively viewing muscle segmentation results.
*   `app.py`: Application entry point.
*   `inference.py`: Inference logic encapsulation.

## 🚀 Quick Start

### Environment Setup
A `requirements.txt` file is provided in the project root.
```bash
pip install -r requirements.txt
```

### Run Core Training (V5)
```bash
python scripts/train_muscle_transfer_v5_l3.py
```

### View Evolution Report
Please refer to `docs/muscle_transfer_evolution/project_evolution_report_v5_cn.md` for a detailed analysis of the loss function design and version iterations.
