# 肌肉迁移学习 V4 前期报告

## 概述

V4版本是对V3的重大增强，核心改进是**导入所有segmentation数据**，实现对非肌肉区域（器官、骨骼、血管等）的精确排除，同时只在未标注区域寻找相似的肌肉组织。

## 背景与问题

### V3版本的局限性

V3采用"先扩后缩"策略，成功实现了100%的标签召回率和11.7倍的扩展比例。但存在以下问题：

1. **仅依赖HU值排除**：只根据HU值（空气<-200，骨骼>300）来排除区域
2. **可能误判器官**：肝脏、脾脏等器官的HU值可能落在肌肉范围内（-29到150）
3. **缺乏解剖学约束**：没有利用已有的器官/骨骼标注来约束预测

### 核心问题

许多内脏器官（如肝脏、肾脏）和软组织的HU值与肌肉重叠，单纯依赖HU值无法有效区分。

## V4解决方案

### 核心思想

```
导入所有segment → 构建非肌肉排除掩码 → 只在未标注区域寻找肌肉
```

### 关键改进

#### 1. 全面的segmentation数据导入

V4导入了TotalSegmentator提供的**107个**非肌肉segmentation文件：

| 类别 | 数量 | 示例 |
|------|------|------|
| 器官（内脏） | 29个 | 肝脏、脾脏、肾脏、胰腺、胃、肠道、心脏、肺等 |
| 骨骼 | 55+个 | 脊椎(C1-L5)、肋骨(24根)、股骨、髋骨、骷髅等 |
| 血管 | 16个 | 主动脉、腔静脉、门静脉、髂动脉等 |

#### 2. 三层排除机制

```
排除区域 = HU排除 ∪ 非肌肉标注区域

其中：
- HU排除：空气(<-200) ∪ 骨骼(>300)
- 非肌肉标注：器官 ∪ 骨骼标注 ∪ 血管
```

#### 3. 已标注区域感知

新增"所有已标注区域掩码"，网络只在**未标注区域**寻找相似肌肉：

```
搜索区域 = 身体区域 - 已知肌肉 - 非肌肉标注 - HU排除
```

### 网络结构改进

输入通道从4增加到5：

| 通道 | 内容 | 说明 |
|------|------|------|
| 0 | CT图像 | 归一化后的CT |
| 1 | HU粗分割 | 肌肉HU范围候选区域 |
| 2 | 已知肌肉标签 | 10种已标注肌肉 |
| 3 | 非排除区域 | 1 - (HU排除 ∪ 非肌肉标注) |
| 4 | **未标注区域** | 1 - 所有已标注区域（新增） |

### 损失函数增强

在V3的基础上新增三个损失分量：

| 损失分量 | 权重 | 作用 |
|----------|------|------|
| 非肌肉区域惩罚 (non_muscle_penalty) | 7.5 | 严格禁止在器官/骨骼/血管区域预测肌肉 |
| 非肌肉相似度惩罚 (similarity_non_muscle) | 1.0 | 确保相似度图在非肌肉区域保持低值 |
| 覆盖奖励（改进） | 1.0 | 仅在未标注区域计算覆盖奖励 |

完整损失函数：

```
L_total = L_label_alignment (3.0)
        + L_coverage_reward (1.0)      # 仅在未标注区域
        + L_exclusion (5.0)
        + L_non_muscle_penalty (7.5)   # 新增
        + L_hu_violation (1.0)
        + L_smoothness (0.2)
        + L_similarity_consistency (1.5)
        + L_similarity_supervision (0.5)
        + L_similarity_non_muscle (1.0) # 新增
```

### 非肌肉排除文件详情

#### 器官（29个）
- 消化系统：肝脏、脾脏、胰腺、胃、结肠、小肠、十二指肠、胆囊、食道
- 泌尿系统：肾脏(左/右)、肾囊肿(左/右)、膀胱、前列腺
- 呼吸系统：肺(5叶)、气管
- 内分泌：肾上腺(左/右)、甲状腺
- 其他：心脏、心耳、脑、脊髓

#### 骨骼（55+个）
- 脊椎：颈椎C1-C7、胸椎T1-T12、腰椎L1-L5、骶骨S1
- 肋骨：左侧12根、右侧12根
- 四肢骨：股骨(左/右)、肱骨(左/右)
- 骨盆：髋骨(左/右)
- 其他：颅骨、胸骨、锁骨、肩胛骨、肋软骨

#### 血管（16个）
- 动脉：主动脉、头臂干、颈总动脉、锁骨下动脉、髂动脉
- 静脉：上/下腔静脉、头臂静脉、门静脉、肺静脉、髂静脉

## 新增评估指标

| 指标 | 说明 |
|------|------|
| non_muscle_overflow | 预测溢出到非肌肉区域（器官/骨骼/血管）的比例 |

该指标直接反映模型是否错误地将器官、骨骼或血管预测为肌肉。

## 可视化增强

V4可视化从7列增加到8列：

1. **CT Image**: 原始CT图像
2. **HU Coarse**: HU值粗分割候选区域
3. **R:Muscle B:NonMuscle**: 红色=已知肌肉，蓝色=非肌肉标注区域
4. **Similarity Map**: 相似度图
5. **Prediction**: 模型预测结果
6. **R:Miss G:New B:Match**: 预测与已知标签对比
7. **R:Overflow G:Good B:Known**: 红色=溢出到非肌肉区域（问题），绿色=未标注区域的预测（好），蓝色=已知肌肉
8. **New Muscle Found**: 在完全未标注区域发现的新肌肉

## 预期效果

### 相比V3的改进

| 方面 | V3 | V4预期 |
|------|-----|--------|
| 排除机制 | 仅HU值 | HU + 107个解剖标注 |
| 器官误判 | 可能存在 | 大幅减少 |
| 搜索区域 | 所有HU合理区域 | 仅未标注区域 |
| 解剖学约束 | 无 | 有（利用已有标注） |

### 核心目标

1. **保持100%召回率**：已标注的10种肌肉必须被完全覆盖
2. **显著降低非肌肉溢出**：预测不应侵入器官、骨骼、血管区域
3. **精确发现新肌肉**：只在解剖学合理的未标注区域寻找肌肉
